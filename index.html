How to Use LocalDrop

1. Same Wi-Fi (Automatic Radar)

Open this website on both your iPhone and Android phone while connected to the same Wi-Fi. Both devices appear on the radar automatically—just tap a device to send files.

2. Mobile Hotspot or Cellular (QR Pairing)

If one phone is on cellular data or a personal hotspot, scan the QR code using the other phone's built-in Camera app, or enter its 6-digit Room Code.

3. Add to Home Screen

On iPhone Safari tap Share → Add to Home Screen. On Android Chrome tap ⋮ → Install app for full-screen AirDrop-like access.
